# 방패-무기 호환성 시스템 Enum 기반 개선

## 현재 문제

`CompProperties_ShieldWeaponIncompatible`가 `List<string> allowedWeaponTags`로 호환성을 판정한다. `weaponTags`는 PawnKind 무기 생성, 트레이더, 호환성 등 여러 용도로 공용 사용되어 결합도가 높다.

```48:54:Project/1.6/Defs/ThingsDefs/Apparel_Shield.xml
			<li Class="NewRatkin.CompProperties_ShieldWeaponIncompatible">
				<allowedWeaponTags>
					<li>RK_WeaponTag_OneHand</li>
					<li>RK_WeaponTag_ShieldCompatible</li>
				</allowedWeaponTags>
				<blockReasonKey>RK_ShieldWeaponIncompatible</blockReasonKey>
			</li>
```

## 신규 설계

### 1. Enum 정의

```csharp
public enum RK_WeaponGripType
{
    OneHand,    // 한손
    TwoHand,    // 양손
    Special     // 특수 (건랜스 등 양손이지만 방패 호환 가능한 무기)
}
```

### 2. 무기 측: CompProperties_WeaponGripType (신규)

- **파일**: `Project/1.6/Source/StaminaShield/CompWeaponGripType.cs` (신규)
- `List<RK_WeaponGripType> gripTypes` 저장
- `SpecialDisplayStats()` 오버라이드로 **모든 무기**(근접/원거리/유틸) 정보 패널에 "무기 파지 유형: 한손" 표시
- `StatCategoryDefOf.Weapon` 카테고리 사용 (근접/원거리 공통 섹션), 낮은 `displayPriority`로 하단 배치

```csharp
public class CompProperties_WeaponGripType : CompProperties
{
    public List<RK_WeaponGripType> gripTypes;
}

public class CompWeaponGripType : ThingComp
{
    // SpecialDisplayStats() → StatDrawEntry로 gripTypes를 문자열화하여 표시
}
```

### 3. 방패 측: CompProperties_ShieldWeaponIncompatible 수정

- **파일**: [CompShieldWeaponIncompatible.cs](Project/1.6/Source/StaminaShield/CompShieldWeaponIncompatible.cs)
- `allowedWeaponTags` 유지 (하위 호환) + `allowedGripTypes` 추가
- `TryIsWeaponAllowed` 로직 변경: `allowedGripTypes`가 있으면 Enum 기반 판정 우선, 없으면 기존 태그 폴백
- `SpecialDisplayStats()` 추가: "호환 무기 유형: 한손, 특수" 표시

### 4. 호환 판정 로직 변경

```
기존: 방패.allowedWeaponTags ∩ 무기.weaponTags → 교집합 있으면 허용
신규: 방패.allowedGripTypes ∩ 무기.gripTypes → 교집합 있으면 허용
```

- [EquipmentUtility_CanEquip_Patch.cs](Project/1.6/Source/StaminaShield/EquipmentUtility_CanEquip_Patch.cs): 변경 불필요 (CompShieldWeaponIncompatible.TryIsWeaponAllowed 내부만 바뀜)

### 5. XML 변경

#### 무기 Def에 Comp 추가 (모든 무기)

각 무기 ThingDef에 `CompProperties_WeaponGripType` 추가:

- **한손 무기** (현재 `RK_WeaponTag_OneHand` 가진 것들): `gripTypes` = `OneHand`
- **양손 무기** (현재 `RK_WeaponTag_TwoHand` 가진 것들): `gripTypes` = `TwoHand`  
- **양손+특수 무기** (현재 `RK_WeaponTag_ShieldCompatible` + `TwoHand` 가진 것들): `gripTypes` = `TwoHand`, `Special`
  - 해당: 건랜스(`Weapon_HighTech.xml` 16행), 랫킨 폴암(`Weapon_Melee.xml` 354행), 플래일(`Weapon_Melee.xml` 560행)
  - UI 표시: "양손, 특수" → 양손이면서 방패 호환 가능한 특수 무기임을 알 수 있음

대상 파일:

- [Weapon_Melee.xml](Project/1.6/Defs/ThingsDefs/Weapon_Melee.xml)
- [Weapon_Range.xml](Project/1.6/Defs/ThingsDefs/Weapon_Range.xml)
- [Weapon_Util.xml](Project/1.6/Defs/ThingsDefs/Weapon_Util.xml)
- [Weapon_HighTech.xml](Project/1.6/Defs/ThingsDefs/Weapon_HighTech.xml)

#### 방패 Def 변경

`allowedWeaponTags` -> `allowedGripTypes`로 교체:

- 소방패/중방패: `OneHand`, `Special`
- 타워방패: `OneHand`
- 배너([Apparel_Util.xml](Project/1.6/Defs/ThingsDefs/Apparel_Util.xml)): `OneHand`

## 마이그레이션 전략

- `allowedWeaponTags`는 코드에서 유지하되, `allowedGripTypes`가 설정되면 우선 사용
- XML은 즉시 `allowedGripTypes`로 전환, `allowedWeaponTags` 제거
- `weaponTags`에서 `RK_WeaponTag_OneHand`/`TwoHand`/`ShieldCompatible` 자체는 제거하지 않음 (PawnKind/Trader에서 사용 중)
