## 참고사항

- Abstract ThingDef는 제외되었습니다 (Name 속성만 있고 defName이 없는 경우)
- 일부 파일에는 ThingDef가 아닌 다른 Def 타입만 포함되어 있습니다 (예: Apparel_Layer.xml)
- 프로젝타일, 탄환 등도 ThingDef로 포함되어 있습니다
