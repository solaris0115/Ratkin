## 5. 방어율·각도 공식 (초안)

### 5.1 커스텀 방어 규칙

- 근접 방어 확률 / 원거리 방어 확률 분리.
- **근접 방어율 (초안)**: `방어력 × 근접 방어 확률(밀리 랭크 커브)` — **최대 70%**.
- **원거리 방어율 (초안)**: `방어력 × 원거리 방어 확률(밀리 랭크 커브)` — **최대 70%** — 문구상 원거리에도 **melee 랭크** 커브를 씀(사격 스킬과 분리할지 **미정** → §7).
- **원거리 방어 각도 (초안)**: `기본 각도 × 밀리 커브 계수(0.7 ~ 1.3)` — 위 “방어율”과 수치 범위가 맞는지 교차 검토 필요.

### 5.2 유저 조절 요소

1. 소재(플라스틸·우라늄·강철 등)
2. 품질(평범 ~ 전설)
3. 폰 밀리 스킬(스탯 커브로 계수 추가 조정)

> **스탯 커브**: 기본 스탯이 아니라 밸런스용으로 임의 곡선을 부여한 값이라는 뜻으로 이해됨.

### 5.3 방어 각도 — 기호 (초안 정리)

| 기호(초안) | 의미 |
|------------|------|
| `ac` (angleCurve) | 각도 커브 값 |
| `mab` / `mb`? | 근접 기본 각도 — 본문에 `mab`·`mb` 혼용 → §7 |
| `rab` / `rb`? | 원거리 기본 각도 — `rab`·`rb` 혼용, 오타 `ranAnglegeBase` → §7 |
| `mae` / `me` | 근접 각도 계수 |
| `rae` / `re` | 원거리 각도 계수 |

- **도탄각**: 품질 계수 **미적용** (초안 명시).

### 5.4 밀리 랭크별 “예시 각도” (초안 테이블)

문서 원문에 따른 참고값(과 §5.5 커브가 완전히 동일한지 **수학적으로 맞춰야 함** → §7).

**밀리 0**

- 소방패: 근거리 100°, 원거리 50°
- 중방패: 근거리 70°, 원거리 70°
- 대방패: 근거리 70°, 원거리 100°

**밀리 20**

- 소방패: 근거리 **180**, 원거리 70° — 단위(180이 도인지) 및 0→20 스케일과 §5.5와의 **정합성 확인** → §7
- 중방패: 근거리 90°, 원거리 100°
- 대방패: 근거리 90°, 원거리 140°

### 5.5 계수 커브 (자연로그 보간 초안)

- 고정 앵커: 0 → 0.5, 20 → 1.2, **상한 1.2**라고 적혀 있음.
- 공식(랭크 `x`): `min(1.2, 0.5 + (0.7 / ln(21)) * ln(x + 1))`
- 아래 표에서 **랭크 30 = 1.23**은 상한 1.2와 **모순** → 표 수정 또는 상한 정의 수정 필요.

| 랭크 | 계수 |
|------|------|
| 0 | 0.50 |
| 5 | 0.91 |
| 10 | 1.05 |
| 15 | 1.14 |
| 20 | 1.20 |
| 30 | 1.23 ⚠ |

- **최종 각도 (원문)**  
  - 근거리: `근거리 방어 각도 = mb + me * C` (또는 `mab` 등 — §7)  
  - 원거리: `원거리 방어 각도 = rb + re * C`

## 6. 방패 타입 특성 (초안 불릿)

### 소형

- 한손 무기 장착 가능; 랜스·일부 양손(`shieldable` 태그) 허용 문구 있음.
- 넓은 커버·근접 유리·원거리 관통에 약·낮은 둔탁·파손 쉬움.

### 중형

- 한손 + 랜스 등 shieldable 양손 허용 (소형과 동일 패턴).
- 전반 밸런스형.

### 대형

- **한손 무기만** — 소·중과 착용 규칙 **상충 여부**는 Def/태그로 확정 필요.
- 원거리·범위·둔탁 강함.

## 7. 정리 필요·부정확·모순 (추후 결정·검증)

아래는 **해결 전까지 구현 근거로 단정하지 말 것** 권장.

1. **방어 원뿔 각도**: “N=45° 기본”과 “방패별 50~180° 예시”의 관계(덮는 범위 중 하나만 쓰는지, 합성인지) 미정.
2. **원거리에 melee 랭크 커브**: 의도 재확인(사격 스킬 분리 vs 단일 스킬).
3. **도탄 확률 식 두 버전**:  
   - A: `(기본배율 + 소재 방어력) * 품질 * melee도탄계수 - 관통`  
   - B: `((기본배율 + 소재 방어력) * 품질 - 관통) * melee도탄계수`  
   괄호·연산 순서가 결과를 바꿈 → **하나로 확정** 필요.
4. **커브 상한 vs 표**: 상한 1.2와 랭크 30 = 1.23 불일치.
5. **기호 통합**: `mab`/`mb`, `rab`/`rb`, `ranAnglegeBase` 오타, `mb+me*C` 형이 §5.4 테이블과 같은 모델인지 불명확.
6. **소방패 근거리 180°**: 타입오거나 다른 스케일일 가능성 — 수치 재검.
7. **이동 시 방향 고정 해제**: 게임감 상 너무 자주 풀릴 수 있음 — 최종 UX 결정.
8. **목표 항목** “(작성 예정)” — v3 완료 조건·비목표 명시 권장.
