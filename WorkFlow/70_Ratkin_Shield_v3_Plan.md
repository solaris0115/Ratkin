## v3 설계 초안 (자유롭게 적어가며 정리)

### 확정적으로 넣을 것들
바라보는 방향에 대한 공격 방어
방향 고정
pawn의 성장에 따른 방어 확률 상승

고민 사항
성장에 다른 방어를 어떤 공식을 이용할 것인지.
그것이 유저에게 재미를 줄것인지.



바라보는 방향에 대한 공격 [방어]
- 근접, 원거리 모두 포함
- pawn이 바라보는 방향으로 들어오는 모든 유형의 공격에 대해서 방어
- 방어각도 좌우 각각 N(기본값:45)도에 대해서만 방어처리. 이외 공격은 방어 불가


방향 고정
- 커맨드로 지정
- pawn을 타겟으로 지정한 경우는 취소될 때 까지 타겟을 계속 추적하며 방향 갱신
- 그외엔 타겟팅한 위치를 시전자가 바라봄
- 기절, 사망, 쓰러짐, 소집해제, 조작불가상태(광란?) 등의 경우 해제
- 이동시에도 해제
- 근접 전투시 근접 전투하는 방향을 바라보다가, 종료되면 다시 고정된 방향을 쳐다보도록 처리

커맨드 조작
- 소집 상태에서만 커맨드가 보임
- 커맨드는 소집 해제시 보이지 않음


[방어] 로직
- 커스텀 방어 규칙을 사용
- 근접 방어 확률, 원거리 방어 확률
- 근접 방어율 공식
  - 방어력 * 근접 방어 확률(pawn melee 랭크에 따른 커브)
  - 최대값 70%
- 원거리 방어율 공식
  - 방어력 * 원거리 방어 확률(pawn melee 랭크에 따른 커브)
  - 최대값 70%
  - 방어 각도 = 기본 각도 * melee커브에 따른 계수(0.7 ~ 1.3)


유저가 컨트롤 가능한 것들
1. 소재(플라스틸, 우라늄, 강철 등 희귀 소재에 따른 방패 성능 변화)
2. 품질 (평범~ 전설)
3. pawn의 melee 스킬 (이것이 상슴함에 따라 스탯커브를 주어추가적인 계수 통제가 가능)
* 스탯 커브란 기존 스탯값인데 값 통제를 위해 임의의 값들을 로그처럼 값 커브를 자유롭게 준 값임.



근거리 방어 각도 = 기본 근거리 각도(방패마다 다름) * melee 랭크에 따른 계수
원거리 방어 각도 = 기본 원거리 각도(방패마다 다름) * melee 랭크에 따른 계수
*도탄각은 품질 계수 안받음

방어 각도 melee 0 레벨 기준
소방패 - 근거리 100, 원거리 50˚
중방패 - 근거리 70˚, 원거리 70˚
대방패 - 근거리 70˚, 원거리 100˚

방어 각도 melee 20 레벨 기준
소방패 - 근거리 180, 원거리 70˚
중방패 - 근거리 90˚, 원거리 100˚
대방패 - 근거리 90˚, 원거리 140˚

기본 방어 각도
커브값 = ac (angleCurve)
근접 기본값 = mab(meleeAngleBase)
원거리 기본값 = rab(ranAnglegeBase)
근접 계수 = mae(meleeAnglecoEfficient)
원거리 계수 = rae(rangeAnglecoEfficient)

각도 커브값 (근거리·원거리 동일, **자연로그 보간**: 0→0.5, 20→1.2 고정, 상한 **1.2**)
근거리 계수 범위 0.5 ~ 1.2
원거리 계수 범위 0.5 ~ 1.2
- 공식 (랭크 `x`): `min(1.2, 0.5 + (0.7 / ln(21)) * ln(x + 1))`

| 랭크 | 계수 |
|------|------|
| 0 | 0.50 |
| 5 | 0.91 |
| 10 | 1.05 |
| 15 | 1.14 |
| 20 | 1.20 |
| 30 | 1.23 |

근거리 방어 각도 = mb+me*C 
원거리 방어 각도 = rb+re*C 

소형 방패
- 한손 무기 장착 가능
- 랜스나 일부 양손 무기 착용 가능 (shieldable 태그)
- 커버 가능한 범위가 넓음
- 소재가 약해서 원거리 공격에는 쉽게 관통됨
- 가볍고 다루기 편해서 근거리 커버율은 좋음
- 낮은 둔탁함 방어
- 비교적 쉽게 파손

- 랜스나 일부 양손 무기 착용 가능 (shieldable 태그)
- 모든 면에서 균형 잡힌 방패

도탄확률 = (기본배율 + 소재 방어력) * 품질 * melee 랭크 따른 도탄 확률 - 관통력
도탄확률 = ((기본배율 + 소재 방어력) * 품질 - 관통력)* melee 랭크 따른 도탄 확률 

원거리
- 공격을 튕겨냄 = 데미지 0
- 공격을 관통당함 = 데미지 받음 + 내구 손상

근거리
- 공격을 막음 = 데미지 0 + 내구 손상
- 공격을 막지 못함 = 데미지 받음
