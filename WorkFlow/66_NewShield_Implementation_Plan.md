# 스태미나 쉴드 구현 작업 계획서

## 작업 개요
- 요청 내용: 스태미나 기반 쉴드 컴포넌트 구현
- 목표: RimWorld 코어 쉴드 시스템을 참고하여 새로운 쉴드 시스템 구현
- 참고: RimWorld 코어 `CompShield` 분석 보고서 (Report/65_RimWorld_Core_Shield_System_Analysis.md)

## RimWorld 코어 쉴드 핵심 기능

### 1. 공격 차단 메커니즘
- 원거리 공격: 차단
  - (스태미나 쉴드: 피해 감소율만큼만 감쇄, 나머지 데미지는 통과, 스태미나도 감쇄된 데미지량에 대해서만 소모, 스태미나 소모량 각각 지정 가능)
- 폭발 공격: 차단
  - (스태미나 쉴드: 피해 감소율만큼만 감쇄, 나머지 데미지는 통과, 스태미나도 감쇄된 데미지량에 대해서만 소모, 스태미나 소모량 각각 지정 가능)
- 근접 공격: 차단 안 함 (통과)
  - (스태미나 쉴드: 피해 감소율만큼만 감쇄, 나머지 데미지는 통과, 스태미나도 감쇄된 데미지량에 대해서만 소모, 스태미나 소모량 각각 지정 가능)
- EMP 공격: 즉시 쉴드 파괴, 차단 안 함
  - (스태미나 쉴드: 통과, 차단 안 함, 파괴 안 함, 스태미나 소모 없음)
- ignoreShields 속성: 통과시킴 (차단 안 함)
  - (스태미나 쉴드: 무조건 통과, 차단 안 함, 스태미나 소모 없음)

### 2. 에너지 관리
- 에너지 소모: 공격 유형별로 소모 (원거리/폭발 공격에 대해 각각 다른 비율 적용)
- 에너지 재충전: Active 상태에서 틱당 일정량 재충전
- 최대 에너지: StatDef로 설정 가능
- 재충전 속도: StatDef로 설정 가능 (틱당)
- (스태미나 쉴드: 공격 유형별 스태미나 소모량 분리, 감쇄된 데미지량에 대해서만 스태미나 소모, 명칭은 스태미나로 통일)

### 3. 쉴드 상태
- Active: 활성 상태, 공격 차단 및 재충전 가능 (에너지 > 0)
- Resetting: 재충전 대기 중, 공격 차단 불가능 (에너지 0 또는 EMP 파괴)
- Disabled: 비활성 상태 (Pawn 충전/셧다운, Dormant)
- (스태미나 쉴드: 스태미나 고갈인 경우만 Resetting, EMP 파괴 없음)

### 4. 쉴드 파괴 및 재충전
- 쉴드 파괴: 에너지 0이 되면 재충전 대기 상태로 전환
- EMP 공격 시: 즉시 에너지 0, 쉴드 파괴
- 재충전 완료: 대기 시간 후 초기 에너지 비율로 재충전
- 재충전 대기 시간: 기본값 3200틱
- (스태미나 쉴드: EMP 공격 시 파괴 안 함, 스태미나 고갈인 경우만 파괴)

### 5. 시각 효과
- 데미지 흡수: 파티클, 플래시, 먼지 효과 표시
- 쉴드 파괴: 이펙터, 폭발 플래시 표시 (사운드 없음)
- 재충전 완료: 효과 없음

### 6. UI 표시
- 에너지 바 및 현재/최대 에너지 표시
- 착용 시 Gizmo 추가
- (스태미나 쉴드: 스태미나 바 및 현재/최대 스태미나 표시)

### 8. 설정 속성
- 재충전 대기 시간
- 쉴드 버블 크기 범위 (최소/최대)
- 데미지당 에너지 손실 비율 (단일 비율)
- 재충전 완료 시 초기 에너지 비율
- (스태미나 쉴드: 공격 유형별 스태미나 소모량 분리, 피해 감소율 추가)

## 구현 세부사항

### CompStaminaShield 컴포넌트 구조
- 스태미나 관리 (현재/최대/재충전 속도)
- 쉴드 상태 관리 (Active/Resetting/Disabled)
- 근접/원거리/폭발 공격에 대해 피해 감소율 적용 (EMP 제외)
- 재충전 기능
- 흡수 효과 표시 (파티클, 플래시, 먼지)
- 파괴 효과 표시 (스태미나 고갈 시에만, 이펙터, 폭발 플래시, 사운드 없음)

### CompProperties_StaminaShield 설정
- RimWorld 코어 CompProperties_Shield 기반
- 에너지 소모량 → 공격 유형별 스태미나 소모량으로 분리:
  - 근접 공격당 스태미나 손실 비율 (기본값: 0.033)
  - 원거리 공격당 스태미나 손실 비율 (기본값: 0.033)
  - 폭발 공격당 스태미나 손실 비율 (기본값: 0.033)
- 피해 감소율 추가:
  - 근접 공격 피해 감소율 (0.0 ~ 1.0, 기본값: 1.0 = 100% 차단)
  - 원거리 공격 피해 감소율 (0.0 ~ 1.0, 기본값: 1.0 = 100% 차단)
  - 폭발 공격 피해 감소율 (0.0 ~ 1.0, 기본값: 1.0 = 100% 차단)
- 재충전 완료 시 초기 스태미나 비율
- XML에서 각 공격 유형별 스태미나 소모량 및 피해 감소율 개별 설정 가능
- 필요시 추가 속성 확장 가능

### PostPreApplyDamage 로직 (핵심 변경사항)
1. 쉴드 상태가 Active이고 착용자가 존재하는지 확인
2. EMP 공격인 경우 차단하지 않고 통과시킴 (스태미나 감소 없음)
3. ignoreShields 속성인 경우 차단하지 않고 통과시킴 (스태미나 감소 없음)
4. 근접/원거리/폭발 공격에 대해 피해 감소율 적용:
   - 피해 감소율만큼 데미지 감쇄, 나머지 데미지는 통과
   - 예: 원래 데미지 100, 감소율 50% → 50 감쇄, 50 통과
5. 감쇄된 데미지량에 대해서만 스태미나 소모:
   - 공격 유형에 따라 다른 스태미나 소모량 적용
   - 예: 감쇄된 데미지 50 * staminaLossPerDamage
6. 스태미나가 0 이하가 되면 쉴드 파괴
7. 스태미나가 남아있으면 흡수 효과 표시
8. 감쇄된 데미지만 차단, 나머지는 통과

### ShieldState 로직 (핵심 변경사항)
- Active: 스태미나 > 0이고 재충전 대기 시간 <= 0
- Resetting: 스태미나 <= 0 (고갈)이고 재충전 대기 시간 > 0
- Disabled: Pawn 충전/셧다운, Dormant 상태 (스태미나와 무관)
- EMP나 기타 이유로는 스태미나 감소 없음 (스태미나 고갈인 경우만 Resetting)

## RimWorld 코어 쉴드 vs 스태미나 쉴드 비교

### 공격 차단 메커니즘 비교

| 공격 유형 | RimWorld 코어 쉴드 | 스태미나 쉴드 | 변경점 |
|---------|------------------|-----------|--------|
| **원거리 공격** | ✅ 차단 | ⚠️ 피해 감소율만큼 감쇄 | **변경: 완전 차단 → 부분 감쇄** |
| **폭발 공격** | ✅ 차단 | ⚠️ 피해 감소율만큼 감쇄 | **변경: 완전 차단 → 부분 감쇄** |
| **근접 공격** | ❌ 통과 (차단 안 함) | ⚠️ 피해 감소율만큼 감쇄 | **변경: 통과 → 부분 감쇄** |
| **EMP 공격** | ❌ 통과 (즉시 쉴드 파괴) | ❌ 통과 (스태미나 감소 없음) | 변경: 즉시 파괴 → 통과만 |
| **ignoreShields 속성** | ❌ 통과 (차단 안 함) | ❌ 통과 (차단 안 함) | 동일 |

### 에너지/스태미나 관리 비교

| 항목 | RimWorld 코어 쉴드 | 스태미나 쉴드 | 변경점 |
|-----|------------------|-----------|--------|
| **명칭** | 에너지 (energy) | 스태미나 (stamina) | **변경: 명칭 통일** |
| **EMP 공격 시** | 즉시 에너지 0, 쉴드 파괴 | 스태미나 감소 없음, 통과만 | **변경: 파괴 → 통과** |
| **스태미나 소모량** | 공격 유형별 분리 | 공격 유형별 분리 (근접/원거리/폭발) | 동일 |
| **스태미나 고갈 시** | Resetting 상태 | Resetting 상태 | 동일 |
| **기타 이유로 감소** | 없음 | 없음 | 동일 |

### 쉴드 상태 비교

| 상태 | RimWorld 코어 쉴드 | 스태미나 쉴드 | 변경점 |
|-----|------------------|-----------|--------|
| **Active** | 에너지 > 0, ticksToReset <= 0 | 스태미나 > 0, ticksToReset <= 0 | 동일 (명칭만 변경) |
| **Resetting** | 에너지 0 또는 EMP 파괴 | 스태미나 <= 0 (고갈만) | **변경: EMP 파괴 제거** |
| **Disabled** | Pawn 충전/셧다운, Dormant | Pawn 충전/셧다운, Dormant | 동일 |

### 주요 변경점 요약

1. **근접 공격**: 코어는 통과 → 스태미나 쉴드는 피해 감소율만큼 감쇄
2. **폭발 공격**: 코어는 완전 차단 → 스태미나 쉴드는 피해 감소율만큼 감쇄
3. **EMP 공격**: 코어는 즉시 파괴 → 스태미나 쉴드는 통과만 (스태미나 감소 없음)
4. **ignoreShields 속성**: 코어는 통과 → 스태미나 쉴드는 통과 (동일)
5. **명칭**: 에너지 → 스태미나로 통일
6. **스태미나 소모량**: 공격 유형별 분리 (XML에서 개별 설정 가능)
7. **피해 감소율**: 완전 차단이 아닌 피해 감소율만큼 감쇄, 나머지 데미지는 통과
8. **스태미나 소모**: 감쇄된 데미지량에 대해서만 스태미나 소모
9. **스태미나 고갈**: 스태미나 고갈인 경우만 쉴드 불가 상태 (EMP나 기타 이유로는 감소 없음)

## 참고사항
- 기존 `Shield` 클래스는 방향성 방어 + 확률 기반 차단 시스템
- 기존 `StaminaShield`는 에너지 기반 쉴드 시스템 (이미 구현됨)
- 스태미나 쉴드는 RimWorld 코어 쉴드 기반이지만 차별화된 특징:
  - **스태미나 기반** (에너지가 아닌 스태미나로 명칭 통일)
  - **근접/원거리/폭발 공격에 대해 피해 감소율 적용** (피해 감소율만큼 감쇄, 나머지 통과)
  - **EMP 공격은 차단 불가능** (통과시킴, 스태미나 감소 없음)
  - **ignoreShields 속성은 무조건 통과** (통과시킴, 스태미나 감소 없음)
  - **공격 유형별 스태미나 소모량 설정 가능** (XML에서 근접/원거리/폭발 각각 설정)
  - **스태미나 소모는 감쇄된 데미지량에 대해서만 적용**
  - **스태미나 고갈인 경우만 쉴드 불가 상태** (EMP나 기타 이유로는 스태미나 감소 없음)
