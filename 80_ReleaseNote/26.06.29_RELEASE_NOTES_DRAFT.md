# Ratkin 릴리즈 노트 — 26.06.29

- 오디세이 조난 맵 생성 시 랫킨 유랑단 구성 문제로 지도 생성이 실패할 수 있던 문제 수정
- 랫킨 유랑단이 제국 팩션과 자동 적대하던 문제 수정
- 도끼·식칼·쟁기·포크·곡괭이 운반 시 품질 표시가 이상할 수 있던 문제 수정
- 한국어 백스토리의 조사·문장 오류 수정
- 털모자·목도리·코이프가 나체주의나 나체 교리와 충돌하던 문제 수정
- 쥑이는총 관련 비활성 패치가 모드 로드 오류를 일으킬 수 있던 문제 수정
- 쥑이는총 가열 페널티가 원거리 재사용 대기시간에 제대로 반영되지 않던 문제 수정
- 테스트용 DPS 기둥이 건축 메뉴에 노출되던 문제 수정
- 유랑단 인간형 구성원이 식량 없이 등장할 수 있던 문제 수정
- 파동 소총을 여러 명이 선택해 공격할 때 일부만 사격하던 문제 수정
- 파동 소총 준비 시간이 장비 스탯 배율을 반영하지 않던 문제 수정
- 방패 착용·아이템 그래픽에 염색 및 재료 색상이 제대로 반영되지 않던 문제 수정
- 매의 눈 특수 트레잇이 무작위 특성 후보에 등장하던 문제 수정

## 변경

- 랫킨 전투복·가스마스크 헬멧의 추위 저항 보강
- 판금·우주 갑옷·투구·진공복 등 랫킨 방어구 무게 완화
- 분리 역학 연구 설명 보강 및 관련 장비 정보 연결 추가
- 예배 참가자가 예배 장소까지 이동할 때 조깅하도록 변경
- 체인소드·화염 체인소드 타격음 볼륨 감소
- 프로토타입 펄스 계열 총기 발사음 볼륨 감소
- 랫킨 장비 착용 제한을 랫킨 유전자 대신 마른 체형 기준으로 변경
- 방패와 함께 착용할 수 있는 무기 판정 조정
- 에너지 방패가 피해를 흡수할 때 쉴드벨트와 유사한 흡수음·이펙트를 사용하도록 변경
- 에너지 방패 충전 방식, 부스트 비용, 최대 에너지 보너스 조정
- 에너지 방패가 고갈되거나 EMP 피해를 받으면 재충전 대기 시간이 생기도록 변경
- 유랑단 등장 시 식량과 기본 필요 수치를 갖춘 상태로 시작하도록 변경
