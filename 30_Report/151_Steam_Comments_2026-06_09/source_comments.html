Follow these exact steps:
Look at the main mod description page above and find the link to the author's GitHub / Older Versions.
Go to that link, look for the v1.5x / Legacy 1.5 release, and download the Source code (zip).
Navigate to your local RimWorld folder on your PC:
...\Steam\steamapps\common\RimWorld\Mods
Extract the ZIP file directly into this Mods folder. (Make sure when you click into the extracted folder, you immediately see files like "About" and "Defs").
Open RimWorld, go to your Mods menu, and enable the new version (it will have a "Local" folder icon next to it instead of a Steam Workshop icon) and don't forget to disable the broken version.
Place it in the exact same spot in your load order where the original mod used to sit, save, and restart.
⚠️ Note: If you use RimPy, just hit "Sort" and "Save" after putting the folder in your local Mods directory and disabling the broken version. Your save file will load perfectly and your pawns will be back!
