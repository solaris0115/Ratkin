# 유니크 Pawn (바닐라 기준)

`UniquePawn` `PawnKindDef` `BackstoryDef` `SolidBio` `등장`

---

## 1. 구성

Def·데이터로 박히는 것만이 아니라, **생성 파이프가 나중에 얹는 층**이 따로 있다.

| 축 | 담당 |
|----|------|
| **PawnKind** | 종족·역할. 장비·무기 대역, 임플란트·시작 헤디프, 능력, 외모 강제, 제노타입 세트(있으면), 이르도·밀스트 전제 등 “역할 스펙” |
| **Backstory** | 유년·성년 슬롯. 직함·서사, 스킬 가산, 일·특성 제약, 체형, 이름 규칙·소지품(정의된 경우) |
| **솔리드(PawnBio)** | (해당 시만) 이름·성별·유년·성년 백스토리를 **한 묶음**으로 고정. 셔플 백스토리와 별 소스 |
| **등장** | 사건·맵젠·퀘스트·세력·시작 등 **어느 경로로** 그 킨드·요청이 들어오는지 |
| **세력·이데올로기·요청** | 팩션·이데오 활성 시 **색이 입혀지는** 층(의복 색, 일부 정신·의식 규칙 등). 킨드만으로 끝나지 않음 |
| **생성기 랜덤층** | 백스토리·킨드에 안 박힌 **스킬 분배·특성·관계** 등은 같은 생성 안에서 따로 돈다. “유니크 Def” 밖 |

유니크를 **이름·백스토리 고정**으로만 보면 **솔리드 + (필요 시) 고정 백스토리 킨드**가 핵심이고, 나머지 축은 **그 위에 얹히거나** 등장 경로가 정한다.

## 2. 데이터 관계

```
PawnKind
├ race / 라벨·연령대·전투력 등 “역할 뼈대”
├ backstory 쪽
│   ├ 카테고리 필터(어떤 셔플 풀과 맞출지)
│   ├ fixedChild / fixedAdult (있으면 그 슬롯은 리스트에서만)
│   └ factionLeader 등 플래그 → 솔리드 시도 조건에 연동
├ 장비·소지
│   ├ 무기·의복(필수/태그/예산)
│   ├ 인벤(고정·옵션)
│   └ 품질·바이오코드 등 부가
├ 신체·외모
│   ├ 시작 헤디프·임플란트·제노타입 세트
│   ├ 머리·피부 등 강제
│   └ 결손·스타일 태그
├ 특성(킨드에서 강제/금지)
├ 능력(Ability)
└ 제노·이데올로기·호칭 등 DLC 연동 필드(있으면)

Backstory (Def 하나)
├ slot (유년 / 성년)
├ 직함·서사
├ skillGains
├ workDisables / requiredWorkTags
├ forcedTraits / disallowedTraits
├ bodyType*
├ spawnCategories + shuffleable (셔플 풀 입장 여부)
├ nameMaker, possessions (정의된 경우)
└ 솔리드 전용이면 shuffleable 꺼짐 → 셔플 풀 제외

PawnBio (솔리드 한 명분)
├ name · gender
├ childhood / adulthood → 위 BackstoryDef 참조
└ pirateKing · rare 등 메타
```

## 3. 생성 루트

모든 경로는 **폰 생성 한 번**으로 모인 뒤, 같은 순서로 백스토리·이름·장비가 처리된다. 유니크 여부는 **킨드 + 생성 요청 + 솔리드 적용 여부**로 갈린다.

| 루트 | 내용 |
|------|------|
| **세력** | 리더 생성·교체, 월드/팩션 붙은 구성원 |
| **집단** | 습격·캐러반·중립 방문 등 **점수/테이블로 한 무리** 뽑기 |
| **사건 단발** | 난민 포드·방랑자 등 **한 명 또는 소수**를 사건이 직접 지정 |
| **퀘스트** | 보상·NPC·목표 폰 |
| **시작** | 시나리오 정착민 |
| **맵젠·베이스 심볼** | 맵에 박혀 있던 시체·단일 폰 등 |

솔리드: 보통 **무작위 일부 + 리더는 거의 항상 시도**, 고정 백스토리만 쓰는 요청이면 솔리드 시도 없음.
