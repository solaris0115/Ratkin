## 1. 초집중 / 신경열 기본값 (일반 Human, 트레잇·장비 없음)

정신력 증폭기(Psylink Neuroformer)로 **정신력 증폭(PsychicAmplifier)** 을 처음 받은 직후 기준. 정신 감응력 100%, 신경열 누적 계수 100%.

### 초집중 (Psyfocus)

| 항목 | 값 | 비고 |
|------|-----|------|
| 최초 획득 시 초집중 | **75%** | 정착민(`SetInitialPsyfocusLevel`) |
| 추가 증폭 시 | `max(현재, 75%)` | 단계 업그레이드 시 하한 보장 |
| 명상 기본 획득률 | **0.5 / 일** | `MeditationFocusGain` (집중 매개체 보너스 제외) |
| 초집중 구간별 일일 소멸률 | 0~25%: **3.5%** / 25~50%: **5.5%** / 50~100%: **7.5%** | 구간이 높을수록 더 빨리 감소 |
| 시전 최소 초집중 (등급별) | 1~2등급: **0%** / 3~4등급: **25%** / 5~6등급: **50%** | 비용 외 별도 하한 |

## 3. 참고 사항

### 제외 항목
- **권위의 연설 (Speech)** — `PsycastBase`가 아닌 작위 전용 의식 능력, 초집중·신경열 없음
- **엔트로피 링크 (EntropyLink)** — Def 주석 처리로 게임 미포함

### 습득 방식
- 정신력 증폭 단계 상승 시 **무작위 1개** 자동 습득
- 정신력 훈련기(Psycast neurotrainer)로 개별 학습 가능

### 비용 해석
- 초집중 비용은 최대 초집중(100%) 대비 비율. 예: 2% = 0.02
- 신경열은 Def 값 × `PsychicEntropyGain` 계수. 일반 Human은 ×1.0
- **신경열 떠넘기기**: 시전자 신경열 0이 되고 대상이 전부 받음 (신경열 생성 아님)
- **신경지진**: 신경열 누적 없음, 시전 후 시전자 5일 `PsychicComa`
