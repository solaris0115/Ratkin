# 심볼릭 링크 생성 - 2024-12-19

## 작업 개요
- 목표: RimworldSource와 RimWorldData 폴더를 현재 프로젝트에 심볼릭 링크로 연결
- 시작 시간: 2024-12-19
- 예상 완료: 약 2-3분

## 계획
1. 현재 작업 디렉토리 확인 및 대상 폴더 존재 여부 확인
2. 기존 심볼릭 링크가 있는지 확인
3. RimworldSource 폴더에 대한 심볼릭 링크 생성
4. RimWorldData 폴더에 대한 심볼릭 링크 생성
5. 생성된 심볼릭 링크 확인

## 진행 상황
### 시작 - 디렉토리 확인
- 상태: 완료
- 내용: 현재 작업 디렉토리와 대상 폴더들 확인
- 결과: D:\GitProject\RimworldSource와 D:\GitProject\RimWorldData 폴더 모두 존재 확인

### 기존 링크 확인
- 상태: 완료
- 내용: 현재 디렉토리에 같은 이름의 폴더나 링크가 있는지 확인
- 결과: 기존 링크 없음 확인

### 심볼릭 링크 생성 시도
- 상태: 완료
- 내용: 관리자 권한으로 mklink 명령어를 사용하여 심볼릭 링크 생성
- 결과: 두 개의 심볼릭 링크 모두 성공적으로 생성됨
- 명령어:
  - `mklink /D RimworldSource D:\GitProject\RimworldSource`
  - `mklink /D RimWorldData D:\GitProject\RimWorldData`

### 링크 검증
- 상태: 완료
- 내용: 생성된 심볼릭 링크들이 정상적으로 작동하는지 확인
- 결과: 두 링크 모두 정상적으로 대상 폴더의 내용에 접근 가능
- 확인된 내용:
  - RimworldSource: RimWorld 소스 코드 파일들 접근 가능
  - RimWorldData: DLC 폴더들(Anomaly, Biotech, Core, Ideology, Odyssey, Royalty) 접근 가능

## 완료/중단 사유
작업이 성공적으로 완료되었습니다. 관리자 권한을 받은 후 심볼릭 링크 생성이 정상적으로 이루어졌습니다.

## 참고사항
- Windows에서 심볼릭 링크 생성에는 관리자 권한이 필요함
- 생성된 링크는 <SYMLINKD> 타입으로 표시됨
- 링크를 통해 원본 폴더의 모든 내용에 정상적으로 접근 가능
